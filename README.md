# AUM Frontend

Admin and public registration frontend for the **AMB. USMAN MOVEMENT (AUM)**.

## Stack

- React
- Vite
- Tailwind CSS
- Axios
- React Router
- Recharts

## API

Create a `.env` file:

```env
VITE_API_URL=http://127.0.0.1:8000
```

For production, set `VITE_API_URL` to the deployed AUM backend URL.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Main routes

- `/` — Admin login
- `/register` — Public volunteer registration
- `/dashboard` — Admin dashboard
- `/volunteers` — Volunteer management
- `/exports` — Export center
- `/profile` — Admin profile
